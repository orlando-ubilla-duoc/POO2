## 📘 Descripción general del sistema
Este proyecto corresponde a la Evaluación Formativa 1 *"Explorando la sobrecarga y sobreescritura en clases derivadas"*. Se trata de un
proyecto en Java que implementa una jerarquía de clases que represente una situación
contextualizada, aplicando polimorfismo mediante métodos sobrecargados (con distintas firmas para una misma funcionalidad)
y métodos sobrescritos (personalizando comportamientos en clases derivadas).

## ⚙️ Instrucciones para clonar y ejecutar el proyecto

1. Clona el repositorio desde GitHub:

    ```bash
        git clone https://github.com/orlando-ubilla-duoc/POO2.git
    ```
2. ingresar a directorio correspondiente a actividad de la semana 1

    ```bash
        cd semana1/SpeedFastApp/
    ```

3. Desde carpeta src, ubicarse en directorio main/java/com/duoc/speedfastapp/ui, y ejecutar el archivo `Main.java` de la siguiente forma.

    ```bash
        java Main.java
    ```
