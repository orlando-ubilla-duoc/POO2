## 📘 Descripción general del sistema
Este proyecto corresponde a la Evaluación Formativa 3 *"Ejecutando tareas en paralelo con hilos en Java"*.<br>
El objetivo es diseñar una estructura de clases en Java utilizando Thread, Runnable y ExecutorService para <br>
ejecutar múltiples tareas de forma simultánea.<br>

Para ello se continuará con el caso de la semana anterior, SpeedFast,  optimizando las entregas de sus repartidores.


---

## 🧱 Estructura general del proyecto

```plaintext
📁 src/
├── interfaces/    # Interfaces con comportamientos a implementar
├── ui/            # Clase principal con el método main
└── model/         # Clases de dominio ( Repartidor, Pedidos, etc )
````

## ⚙️ Instrucciones para clonar y ejecutar el proyecto

1. Clona el repositorio desde GitHub:

    ```bash
        git clone https://github.com/orlando-ubilla-duoc/POO2.git
    ```
2. ingresar a directorio correspondiente a actividad de la semana 4

    ```bash
        cd semana4/SpeedFastApp/
    ```

3. Desde carpeta src, ubicarse en directorio main/java/com/duoc/speedfastapp/ui, y ejecutar el archivo `Main.java` de la siguiente forma.

    ```bash
        cd src/main/java/com/duoc/speedfastapp/ui
        java Main.java
    ```
