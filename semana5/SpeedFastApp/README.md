## 📘 Descripción general del sistema
Este proyecto corresponde a la Evaluación Sumativa 2 *"Sincronizando procesos en sistemas concurrentes"*.<br>
El objetivo es diseñar una estructura de clases en Java utilizando Thread, Runnable, synchronized y ExecutorService para <br>
ejecutar múltiples tareas de forma simultánea y sincronizada para evitar duplicidades o incongruencias en la ejecución.<br>

Para ello se continuará con el caso de la semana anterior, SpeedFast,  optimizando las entregas de sus repartidores.

## ⚙️ Instrucciones para clonar y ejecutar el proyecto

1. Clona el repositorio desde GitHub:

    ```bash
        git clone https://github.com/orlando-ubilla-duoc/POO2.git
    ```
2. ingresar a directorio correspondiente a actividad de la semana 5

    ```bash
        cd semana5/SpeedFastApp/
    ```

3. Desde carpeta src, ubicarse en directorio main/java/com/duoc/speedfastapp/ui, y ejecutar el archivo `Main.java` de la siguiente forma.

    ```bash
        cd src/main/java/com/duoc/speedfastapp/ui
        java Main.java
    ```
